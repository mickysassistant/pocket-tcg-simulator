## Codebase Patterns

### Testing Pattern
- Tests use a custom test framework with `runTest(name, fn)` helper
- Helper functions: `assert()`, `assertEqual()`, `assertDeepEqual()`
- Tests are in `tests/` directory with `.test.js` extension
- Run tests with: `find tests -name "*.test.js" -exec node {} \;`

### Game System Pattern
- Game state is in `GameState` class
- Systems are passed `gameState` in constructor
- Systems interact via `AbilitySystem`, `KoTriggerSystem`, etc.
- Attack system supports: energy costs, weakness, damage scaling, recoil, temporary effects, target selection (Active/Banque)

### Attack Definition Pattern
- Attacks are objects: `{ name, damage, energyCost?, damageScaling?, recoilDamage?, temporaryDefenderEffect?, ... }`
- `executeAttack(playerId, attack, target?)` executes an attack
- Targets: `{ location: 'active' | 'banque', pokemonId? }`

### Spread Damage Pattern (NEW - GAP-016)
- Spread damage applies to opponent's Benched Pokémon
- Config: `spreadDamage: { amount: number, target: 'banque' | 'all' }`
  - `target: 'banque'` - damage only to Benched Pokémon (Raichu Gigashock pattern)
  - `target: 'all'` - damage to all opponent's Pokémon (Active + Banque)
- Damage to each Benched Pokémon is calculated independently
- Each Benched Pokémon's damage goes through full damage calculation (modifiers, weakness, etc.)
- KO triggers fire for each Benched Pokémon that is KO'd
- Result includes `spreadDamageResults` array with damage to each Benched Pokémon
