## Codebase Patterns

### Testing Framework
- Tests use a custom assertion framework (assert, assertEqual, assertDeepEqual)
- Test utilities: createGame(), setActive(), addEnergy()
- Run tests with: `for test in tests/rules/*.test.js; do node "$test" || exit 1; done`

### Project Structure
- Main game logic in `src/game/`
- Tests in `tests/rules/` and `tests/integration/`
- Main entry point: `src/index.js`

### Attack System Pattern
- AttackSystem in `src/game/attack-system.js` handles attack execution
- Damage modifiers flow: base → scaling → modifiers → weakness → final
- Attack config supports: damageScaling, benchScaling, extraEnergyBonus
- Result includes: baseDamage, damageScaling, benchScaling, extraEnergyBonus, bonusApplied, reductionApplied, weaknessApplied, finalDamage

### Energy Cost Pattern
- Energy costs are arrays of energy type strings
- Colorless energy can be satisfied by any energy type
- Specific types require exact match

### Ability System Pattern
- AbilitySystem handles passive abilities and damage modifiers
- Supports: damage_bonus, damage_reduction, damage_prevention, opponent_damage_reduction
- Register abilities with `abilitySystem.registerAbility()`

### Extra Energy Bonus Pattern (GAP-019)
- Extra energy = total attached energy - energy cost
- Two modes: perExtraEnergy (scales) or threshold+bonusAmount (fixed)
- energyType filter: optional, counts only specific energy type
- When halveHp is true, extraEnergyBonus is skipped (set to 0)
- Integrates with damageScaling and benchScaling

## 2026-02-19 - GAP-019: [Importante][C2] Bonus por "energía extra" adjunta (Blastoise)

### What was implemented
- Added `calculateExtraEnergyBonus()` method to AttackSystem
- Calculates bonus damage based on energy beyond the attack cost
- Supports two modes:
  - **perExtraEnergy**: damage scales with extra energy count (e.g., Blastoise: 30 per extra [W])
  - **threshold + bonusAmount**: fixed bonus if extra energy >= threshold (e.g., Lapras: +50 if >=2 extra [W])
- Energy type filtering via `energyType` property (optional)
- Integrated into `executeAttack()` damage calculation flow
- Added `extraEnergyBonus` to attack result object
- Added `extraEnergyBonus` to `calculateDamage()` dry-run method
