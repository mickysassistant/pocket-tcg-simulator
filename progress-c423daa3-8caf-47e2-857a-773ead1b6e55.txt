## Codebase Patterns
- Project uses JavaScript (Node.js), no TypeScript
- Test files are run directly with `node <test-file>.js`
- No build or typecheck scripts defined in package.json
- Main systems: AttackSystem, AbilitySystem, EnergySystem, EvolutionSystem, TurnManager
- Tests use custom assert functions (assert, assertEqual, assertDeepEqual)
- Tests report with ✓/✗ and summary at the end
- Attack execution flow: energy cost → base damage → damageScaling → benchScaling → modifiers → weakness → apply damage
- Game state in `gameState.players[playerId]` with activePokemon and banque (bench)
- Energy is in pokemon.energy array with { type, id } objects
- Bench (banque) is an array of Pokémon objects
- Pocket TCG maximum bench size is 3 Pokémon
