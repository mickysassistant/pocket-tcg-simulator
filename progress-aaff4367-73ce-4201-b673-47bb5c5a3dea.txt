## Codebase Patterns
- Project uses plain JavaScript (no TypeScript)
- Tests use custom test runner with manual assertions and run with `node tests/*.test.js`
- Main entry point is src/index.js which exports createGame and game systems
- Game systems: GameState, TurnManager, DrawSystem, EnergySystem, EvolutionSystem, SupporterSystem, DeckManager, WinCondition
- Tests use assert.strictEqual and other manual assertions
- Project uses Puppeteer for E2E smoke tests
- CLI commands are in src/cli/commands/*.js, each exporting a handler function
- CLI services are in src/cli/services/*.js for shared functionality
- All CLI commands support --json output via argv.formatOutput()
- All CLI errors include stable reason codes (e.g., MISSING_ARGUMENT, UNKNOWN_SUBCOMMAND)
- Config stored in ~/.tcgp/config.json (respects XDG_CONFIG_HOME if set)
