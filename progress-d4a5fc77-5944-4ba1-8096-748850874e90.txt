## Codebase Patterns
- Testing uses custom assertion helpers (assert, assertEqual, assertDeepEqual) and runTest function
- Tests are run directly with `node <test-file>.js` (not using a test framework)
- Game state has `banque` (bench) array for each player
- AttackSystem.executeAttack can target either active or benched Pokémon (GAP-015)
- Energy costs use format: ['type1', 'type2', ...] with colorless being flexible
- Weakness adds +20 damage in Pocket TCG (not 2x like physical TCG)
- Damage modifiers flow: base → bonus → reduction → opponent reduction → weakness → final
- All game state mutations go through the GameState class methods
- Turn logging is done via gameState.turnLog.push({type, ...})
- KO-triggered abilities (e.g., Pyukumuku Innards Out) only work when the KO'd Pokémon is in the Active Spot, not when benched - this is per card text
- Temporary defender effects are only applied if the defender survives the attack (is not KO'd)
- Temporary effects use a Map with `${playerId}:${pokemonId}` keys for storage and isolation
- Effects have a turnsRemaining counter that decrements on advanceTurn() calls
- Effects are cleared immediately on switch/evolution via clearEffectsForPokemon()
