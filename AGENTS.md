# Developer Agent - Pokemon TCG Pocket Simulator

## Project Stack
- **Language:** JavaScript (migrating to TypeScript)
- **Runtime:** Node.js + Browser (ES2022 modules)
- **TypeScript:** v5.9.3 (strict mode, gradual migration with allowJs)
- **Build Tool:** TypeScript compiler (tsc)
- **Dev Server:** serve (via npm run serve)

## Project Structure
```
pocket-tcg-simulator/
├── css/              # Stylesheets
├── js/               # Source JavaScript (will migrate to TypeScript)
│   ├── data/         # Data loading modules
│   ├── engine/       # Game engine (game-state, coin, turn-manager, etc.)
│   └── main.js       # Entry point
├── dist/js/          # Compiled output (generated by tsc)
└── index.html        # Main HTML entry point
```

## Development Commands
- `npm run build` - Compile TypeScript/JavaScript to dist/js/
- `npm run typecheck` - Type check without emitting files
- `npm run serve` - Start dev server on port 3000

## Testing
- Tests use node:test pattern with Node.js ES modules
- Run individual tests: `node --input-type=module -e "import('./js/engine/coin.test.js').then(m => m.runCoinTests())"`
- Build pipeline tests: `node test-build-pipeline.test.js`

## Key Patterns
- **Gradual Migration:** tsconfig uses `allowJs: true` to compile existing .js files while maintaining strict mode
- **Module System:** ES2022 modules (`type="module"` in package.json not set, using .mjs or inline modules)
- **Output Structure:** dist/js/ mirrors the js/ source structure

## Migration Strategy
1. Initialize TypeScript toolchain (US-001) ✓
2. Gradually migrate .js files to .ts
3. Update tsconfig include patterns as migration progresses
4. Maintain backward compatibility until complete migration
